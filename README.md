# os2-issue-and-pr-templates
Repo for cooperation and maturing Issue templates and PR templates for our os2 projects and products

The overall purpose of this repository is to facilitate the establishment of a liberary of OS2 Git Issue and PR templates, by providing a place for discussions, descisions and experiences to shared.

A OS2display pilot on the topic has been initiated january 2025, in collaboration with OS2borgerpc.
The goal of this initeative is to provide OS2 with proof of consept on a set of templates.
To support this goal, workproduct, discussions and descissions made during this pilot will be documented in this repo.
