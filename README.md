# os2-issue-and-pr-templates
Repo for cooperation and maturing Issue templates and PR templates for our os2 projects and products

The overall purpose of this repository is support knowledgesharing and collaborative development of Issue and PR templates to be used in the OS2 product portfolio.

The end goal is the establishment og a commontly used OS2 template liberary, build upon the experiences and results made in the OS2 products. 

The overarching plan is to develop such liberary as follows.
1. **Initiation of work**, where basic templates are gathered in this repository
3. **Preliminary product Pilot**, where OS2BorgerPc and OS2display in collaboration implements and improves the identifyed templates,
4. **OS2 firstmover POC**, where the outcome of the Preliminary POC are implemented i 2-4 additional products og project.
5. **Template package MVP**, where a suggested standard setup (v 08) are consolidated in a template package
6. **Template Package Maturity project**, where the template package and its are matured and improved in order to provide a OS2 Preferred Git template liberary)
7. **Template Package Instutionalisation initiative**, where the structure for governing sustainability, dissermination afn further development of the Template package is implemented.
8. **Template package implementation initiative**, where the developed template package are implemented as a prefered standard across the product and project protfolio

The strategy is to walk the talk in this repositoru, when it comes to standardisation and automation of Issues and PR's:
- All initiatives related to the decribed scope of work will be described, discussed, developed and presented in this repository
- Issues will be used as the anchorepoint for alle discussions, descissions, agreement and scope specifications.
- Labels will be used proactivly in order to organize Issues and PR's in themes, states and types.
- The identifyed templates and suggested automaiton will be implemented in this repository, as a preliminary POC.
